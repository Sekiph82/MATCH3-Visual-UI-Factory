# Unity authoring project Assets

The authoring host intentionally contains **no branded game assets**. Its shared
source lives under `unity_package/` via local UPM reference. The Editor
Dashboard and manual Sprite Preview are found at Tools > MATCH3.

Owner-supplied original/licensed sources must be placed in the external
content-addressed store and reviewed before any game publication. Do not copy
screenshots from chat or unlicensed code/assets into this folder.
