# VF-09 QA and Validation
The current `validate_design.py`, `Tools/validate_manifest.py` and standalone
Python unit tests perform STRUCTURAL CHECKS ONLY. Future automated image and
Unity visual QA must inspect transparent borders, sprite atlases, thresholds,
contrast, safe-area, scene diff, animation, particle performance, source
licensing, genuine EditMode/PlayMode tests and physical device captures.
Creative owner approval and independent audit remain separate authorities.
