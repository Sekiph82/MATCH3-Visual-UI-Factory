# VF-05 | Multiple animation formats

Planned: sprite-sheet clips for 2D mascots, optional skeletal rig clips for
characters, 3D rig/part transforms where game content actually needs them.
Each clip has explicit frames/curves, pivots, timing, events, replay semantics,
interruption policy and reduced-motion fallback. Initial manual frame playback
is available in the VUF Editor preview; no full animation builder yet.
